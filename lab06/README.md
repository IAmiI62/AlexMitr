
*Проверьте четыре способа объявления* **Pi**.
* ```const auto Pi = acos(0) * 2;```
* ```constexpr auto Pi = std::acos(0) * 2;```
* ```const auto Pi = acos(x) * 2;```
* ```constexpr auto Pi = std::acos(x) * 2;```

*Что можно сказать об этих вариантах? Проверьте, в каких вариантах объявляется константа этапа трасляции.*

*Тексты программ разместите в папке с номером задания*

const auto Pi = acos(0) * 2 — объявляет константный объект времени выполнения. (Не является константой этапа трансляции).
constexpr auto Pi = std::acos(0) * 2 — объявляет константу этапа трансляции. Значение вычисляется во время компиляции, так как аргумент 0 — это литерал.
const auto Pi = acos(x) * 2 — объявляет константный объект времени выполнения. Значение x станет известно только при запуске программы.
constexpr auto Pi = std::acos(x) * 2; — Ошибка компиляции. Ключевое слово constexpr требует, чтобы значение было вычислено на этапе компиляции, 
но переменная x не является константным выражением.


### Задание 2 **(2)**
*Проверьте работу следующей программы на С++*
```
#include <iostream>
int main() {
   {
      int x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   {
      double x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   return 0;
}
```
*Нужны ли в этой программе вложенные фигурные скобки? Дайте подробный ответ с объяснением причин.*
Да, фигурные скобки необходимы. 
Без них компилятор выдаст ошибку, так как переменные x и y будут объявлены дважды в одной и той же области видимости (внутри функции main).
Скобки создают два независимых блока, позволяя использовать одинаковые имена для переменных разных типов.

### Задание 3 **(2)**
*Проверьте работу следующего фрагмента программы на С++.*
```
int s = 0;
for (int i = 0; i < 4; i++) {
   for (int i = 0; i < 3; i++) {
      s += i;
   } 
   s += i; 
}
std::cout << s;
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

Программа выведет 18

внутренний цикл всегда прибавляет 0+1+2 = 3 к s. 
Внешний цикл выполняется 4 раза с i от 0 до 3. 
После завершения внутреннего цикла s += i прибавляет значение внешней переменной i. 
Итог: (3+0) + (3+1) + (3+2) + (3+3) = 18

### Задание 4 **(2)**

*Проверьте работу следующего фрагмента программы на* **Python**.
```
s = 0
for i in range(4):
   for i in range(3):
      s += i
   s += i
print(s)
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

*На основе этих примеров поясните различия между* **С++** и **Python** *при работе с переменными*.

Программа выведет 20.

В Python внутренний цикл перезаписывает ту же самую переменную i. 
После завершения внутреннего цикла i всегда равна 2. Внутренний цикл прибавляет 3 (0+1+2). 
Внешний цикл выполняется 4 раза и после каждого раза прибавляет 2. 
Итог: (3+2) + (3+2) + (3+2) + (3+2) = 20).

Различие C++ и Python:

В C++ циклы имеют блочную область видимости. Внутренняя переменная i уничтожается, как только внутренний цикл заканчивается. 
Поэтому s += i обращается к внешней i (которая равна 0, 1, 2, 3). Результат — 18.

В Python циклы не создают новую область видимости. Внутренний цикл использует ту же самую переменную i, что и внешний, 
просто перезаписывая её. 
После внутреннего цикла i остается равной 2 и продолжает существовать.

### Задание 6 **(2)**

*Рассмотрим следующий фрагмент программы. Эта программа 1000000 раз обменивает значения двух длинных 
строк с использованием третьей строки. Проверьте, насколько быстро она работает.*

```
std::string a(100000, 'a');
std::string b(100000, 'b');
for (int i=0;i<1000000;i++) {
   std::string c(a);
   a = b;
   b = c;
}
std::cout << a[0] << b[0];
```
*Попробуйте использовать для обмена значений строк функцию* **swap**. 
*Проверьте, изменилось ли время работы. В чем ошибка исходной программы?
Исправьте исходную программу, чтобы ускорить ее работу. Изменения не должны 
затрагивать общий вид программы (присваивания, использование временной переменной).*


1. использованием swap
Если заменить тело цикла на std::swap(a, b);, программа будет работать мгновенно. 
Функция swap просто меняет местами внутренние указатели на данные в памяти, не копируя сами символы (100 000 байт).

2. В чем ошибка исходной программы?
Ошибка в том, что исходная программа на каждой из 1 000 000 итераций выполняет глубокое копирование (copy semantics).

std::string c(a); — копирует 100 000 символов.

a = b; — копирует 100 000 символов.

b = c; — копирует 100 000 символов.
Это приводит к огромным затратам времени и памяти (миллиарды скопированных байт).

3. Исправление (с сохранением общего вида)
По условию нельзя менять структуру (присваивания через c). 
Значит, нужно включить семантику перемещения с помощью std::move. 
Тогда строки будут не копироваться, а «передавать» свои ресурсы:
```
std::string a(100000, 'a');
std::string b(100000, 'b');
for (int i=0; i<1000000; i++) {
    std::string c(std::move(a));
    a = std::move(b);            
    b = std::move(c);           
}
std::cout << a[0] << b[0];
```
### Задание 7 **(2)**

*Рассмотрим программу на языке* **Python**.
```
a = 'Hello world'
print(a, id(a))
b = a
print(b, id(b))
a += ' and goodbye'
print(a, id(a))
print(b, id(b))
```
*Объясните ее работу. В какой момент создавались строки? 
Что означает значение, возвращенное функцией* **id**?

Изначально a и b ссылаются на один и тот же объект (их id совпадают).

Строки в Python неизменяемы. Операция a += ' and goodbye' не меняет старую строку, 
а создает новый объект в памяти и привязывает к нему переменную a. 
Поэтому id(a) изменится.

Переменная b продолжает ссылаться на старую строку 'Hello world', ее id не меняется.

Значение id — это уникальный идентификатор объекта (в Python — его адрес в памяти)
