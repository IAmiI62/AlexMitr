### Задание 5. **(2)**

*Объясните работу фрагмента программы на С++. В частности, почему* $x+x-x=x$, *но при этом*
$(x\cdot 2)/2\neq x$? *В отчете надо привести вычисления, приводящие к ответу.*
```
unsigned short x = 40000;
unsigned short y = x + x;
unsigned short z = x * 2;
y = y - x;
z = z / 2;
std::cout << y << " " << z << std::endl;
```

unsigned short — 16 бит, диапазон от 0 до 65535.
x = 40000.
x + x = 80000.
Но 80000 больше 65535, поэтому:
80000 - 65536 = 14464.
Значит, y = 14464.
x * 2 = 80000, при присваивании в unsigned short тоже получаем 14464.
Значит, z = 14464.
y = y - x = 14464 - 40000 = -25536.
Приводим к беззнаковому 16-битному:
-25536 + 65536 = 40000.
То есть y = 40000.
z = z / 2 = 14464 / 2 = 7232.

Вывод: 40000 7232

Почему x + x - x = x, но (x * 2) / 2 не равно x:
при x + x переполнение «съедает» лишнее, но затем вычитание возвращает исходное значение по модулю 2^16.
А при x * 2 переполнение уже произошло до деления, поэтому после деления на 2 исходное число не восстанавливается.

### Задание 8 **(2)**

*Найдите результаты вычисления следующих выражений без использования компьютера
или калькулятора. Процесс вычислений должен быть отображен в отчете.*
* `(1000 & 100) << 10`
* `(1000 >> 4) & 15`
* `~1234 + 1234`
* `(1000 ^ 500) & 63`
* `(100 << 3) + (100 >> 3)`


1. (1000 & 100) << 10
1000 = 1111101000
100 = 0001100100
Побитовое И:
1111101000
& 0001100100
= 0001100000
0001100000 = 64 + 32 = 96
96 << 10 = 96 * 1024 = 98304
Ответ: 98304.

2. (1000 >> 4) & 15
1000 >> 4 = 1000 / 16 = 62 (целая часть)
62 & 15 = 62 mod 16 = 14
Ответ: 14.

3. ~1234 + 1234
В дополнительном коде:
~x = -x - 1
Поэтому:
~1234 = -1235
-1235 + 1234 = -1
Ответ: -1.

4. (1000 ^ 500) & 63
1000 = 0x3E8
500 = 0x1F4
1000 ^ 500 = 0x3E8 ^ 0x1F4 = 0x21C = 540
540 & 63 = 540 mod 64 = 28
Ответ: 28.

5. (100 << 3) + (100 >> 3)
100 << 3 = 100 * 8 = 800
100 >> 3 = 100 / 8 = 12 (целая часть)
